== 磁盘
NAME     SIZE TYPE FSTYPE MOUNTPOINTS
fd0        4K disk
sda       40G disk
├─sda1    39G part ext4   /
├─sda14    4M part
├─sda15  106M part vfat   /boot/efi
└─sda16  913M part ext4   /boot
sdb        8G disk
sdc        4G disk
sdd        4G disk

sda 是系统盘（/ 在 sda1），脚本按 ROOT_DISK 校验后拒绝使用它。
本轮夹具用 sdb（8G，建 2G 分区）与 sdc（4G，只导入不挂载）。
sdd（4G）是虚拟机里另一块闲置盘，本轮没有使用，脚本只接受显式给出的
SPARE_DISKS="sdb sdc"，不会因为“看到一块空盘”就去动它。

== Samba 与 ACL（夹具，不是被测物）
samba 2:4.19.5+dfsg-4ubuntu9.8（smbd --version：Version 4.19.5-Ubuntu）
acl 2.3.2-1build1.1
/usr/bin/smbpasswd /usr/bin/pdbedit /usr/bin/getfacl /usr/bin/setfacl
/usr/sbin/useradd /usr/bin/getent
smbd：active / enabled（虚拟机上本来就装着并开着；P08.1 不改 smb.conf，
验收里有一条断言专门核对 smb.conf 逐字节未变）

安装方式（一次性夹具）：apt 包 samba 与 acl，在本轮之前为验证“能力检测读的是
机器上真实存在的工具”而装进这台一次性虚拟机。P08.1 的检测逻辑不假设任何机器
装了什么：缺哪个工具就报哪个阻塞码（TOOL_MISSING 系列），两个都缺才判
available=false——真机上“装了什么”由这一层读出来，不由代码默认。
